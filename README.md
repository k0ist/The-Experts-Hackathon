# Продуктовая аналитика и A/B-тестирование в цифровом маркетплейсе

Независимая оценка результатов A/B-теста новой AI-модели рекомендаций на главной странице мобильного приложения крупного российского маркетплейса. Проект выполнен в рамках хакатона **School of Analytics — The Experts (2026)**.

**Файл решения:** `The_Experts_Hackathon.ipynb`

## Контекст

В июле 2026 продуктовая команда маркетплейса провела 30-дневный A/B тест новой AI-модели рекомендаций против текущей рекомендательной системы (Control). Задача — независимая оценка результатов эксперимента и рекомендации Product Leadership Team по дальнейшей судьбе модели.

Решение принято исключительно на основе предоставленного датасета (10 таблиц: users, experiment_assignments, sessions, impressions, clicks, orders, products, sellers, premium_subscriptions, support_tickets), без возможности провести дополнительные эксперименты или сбор новых данных.

## Найденные проблемы качества данных

| Проблема | Масштаб | Решение |
|---|---|---|
| Contamination групп эксперимента (баг `assignment_service_bug`) | 300 пользователей назначены одновременно в `control` и `test` | Исключены из анализа |
| Отрицательная маржа (`gross_margin_rub < 0`) | 462 заказа (~6.2%) | Проверена связь с группой эксперимента, не удалена — легитимный бизнес-кейс скидок |
| Пропуски `delivery_fee_rub` | 303 заказа (~4.1%), похоже на MCAR | Заполнены медианой по `category` |
| Дубли событий (`is_duplicate_event`) | ~0.3% показов | Отфильтрованы перед расчётом воронки |
| Боты (`is_bot_candidate`) | ~0.8% пользователей, сбалансированы между группами | Исключены из анализа |

**SRM-тест пройден** после очистки данных (control: 24 674, test: 25 026, p = 0.114) — рандомизации можно доверять.

## Методология

- Все метрики эксперимента считаются **на уровне пользователя** (юнит рандомизации), а не событий — во избежание псевдоповторности.
- Долевые метрики (CTR, конверсия, Return Rate, Premium Conversion, Support Rate) — **two-proportion z-test**.
- Непрерывные скошенные метрики (GMV, AOV) — **bootstrap**.
- **AOV и Return Rate считаются только среди конвертировавших пользователей** — иначе метрика смешивает эффект на конверсию с эффектом на сам чек/возврат.
- **Gross Margin Rate** считается как агрегированное отношение Σmargin/ΣGMV, а не среднее по пользователям — иначе метрика растёт вместе с GMV почти автоматически и не отражает реальную маржинальность.
- Поправка на множественные сравнения (**Benjamini-Hochberg**) применена при одновременной проверке нескольких метрик и сегментов.
- Гетерогенность эффекта по сегментам проверяется формальным статистическим тестом (interaction/`proportions_ztest` по каждому срезу с BH-поправкой), а не сравнением p-value между сегментами напрямую.

## Ключевые результаты

Тестовая группа показывает положительный лифт по всем метрикам воронки:

| Метрика | Control | Test | Лифт |
|---|---|---|---|
| CTR (event-level) | ~7.3% | ~9.1% | +23.5% |
| Purchase Rate | ~11.8% | ~15.2% | +28.6% |
| Repeat Purchase Rate | ~7.0% | ~10.9% | +55.3% |
| Return Rate | ~5.5% | ~6.8% | +23.3% |
