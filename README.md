# \# Продуктовая аналитика и A/B-тестирование в цифровом маркетплейсе

# 

# Независимая оценка результатов A/B-теста новой AI-модели рекомендаций на главной странице мобильного приложения крупного российского маркетплейса. Проект выполнен в рамках хакатона \*\*School of Analytics — The Experts (2026)\*\*.

# 

# \## Контекст

# 

# В июле 2026 продуктовая команда маркетплейса провела 30-дневный A/B тест новой AI-модели рекомендаций против текущей рекомендательной системы (Control). Задача — независимый анализ результатов и рекомендации Product Leadership Team по дальнейшей судьбе модели: внедрять на всех пользователей, придержать, или провести дополнительные исследования.

# \## Ключевые находки

# 

# \- \*\*Смешение (контаминация) групп эксперимента\*\*: часть пользователей была назначена одновременно в обе группы из-за бага сервиса присвоения (`assignment\_source = "assignment\_service\_bug"`) — исключены из анализа.

# \- \*\*SRM-тест пройден\*\* после очистки данных — рандомизации можно доверять.

# \- \*\*Отрицательная маржа\*\*: у части заказов `gross\_margin\_rub < 0` — проверена связь с группой эксперимента.

# \- Новая модель показывает положительный лифт по метрикам воронки (CTR, конверсия, повторные покупки), при этом растёт и доля возвратов — итоговый эффект на прибыльность требует отдельной оценки через Gross Margin Rate, а не только через рост выручки.

# 

# Подробные выводы и итоговая рекомендация — в разделах 6–7 ноутбука.

# 

# \## Методологические принципы

# 

# \- Все метрики эксперимента считаются \*\*на уровне пользователя\*\* (юнит рандомизации), а не на уровне событий — во избежание псевдоповторности.

# \- Для долевых метрик используется \*\*two-proportion z-test\*\*, для скошенных непрерывных метрик — \*\*bootstrap\*\*.

# \- Применена поправка на множественные сравнения при одновременной проверке нескольких метрик и сегментов.

# \- AOV и Return Rate считаются только среди конвертировавших пользователей, чтобы не смешивать эффект на конверсию с эффектом на сам чек/возврат.

# \- Гетерогенность эффекта по сегментам проверяется формальным статистическим тестом, а не сравнением p-value между сегментами напрямую.
